# Bei SkiZones mitmachen

Danke für dein Interesse an SkiZones!

## Rückmeldungen und Beiträge

- **Community & Fragen:** [KoSchpendium / SkiZones auf Discord](https://discord.gg/AFXtwWvm)
- **Fehler:** [Bugreport-Formular](https://github.com/chekento/SkiZones/issues/new?template=bug_report.yml)
- **Funktionen:** [Feature-Wunsch](https://github.com/chekento/SkiZones/issues/new?template=feature_request.yml)
- **Regeln und Hinweise:** [Community-Leitfaden](docs/COMMUNITY.md)

Bitte prüfe zunächst vorhandene Issues und nenne bei Fehlern nach Möglichkeit Version, Plattform, Reproduktionsschritte und erwartetes Ergebnis.

## Pull Requests

Diskutiere größere Änderungen möglichst vorab in einem Issue. Halte Änderungen fokussiert und dokumentiere betroffene Spielmechaniken, Bedienoberflächen und Migrationsfälle. Teste Änderungen nach Möglichkeit mit den in der [README](README.md#entwicklung-und-qualität) dokumentierten Godot-Tests und achte auf deutsche und englische UI-Texte.

Mit einem Pull Request wird keine automatische Übernahme zugesagt. Für das Repository besteht derzeit keine allgemeine Open-Source-Lizenz; die rechtlichen Hinweise in der README gelten weiterhin.
