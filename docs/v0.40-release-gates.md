# SkiZones v0.40 — Release gates and implementation contract

Status: specification only; no claim of implemented fixes.

## P0 — save data safety
- On boot, never rewrite or migrate a save automatically. Enumerate original files and backups read-only.
- Distinguish JSON syntax failure, truncated data, schema mismatch, unknown version, missing optional fields, invalid required fields, and filesystem I/O failure.
- Keep originals byte-for-byte unchanged. Recovery produces a separate candidate; only replace an active slot after user confirmation and successful round-trip verification.
- Save atomically via temporary file and verified read-back before promoting; preserve last known-good backup.
- Build versioned migrations for every observed schema from v0.19 to v0.39.1. Preserve known gameplay state (buildings, lifts, paths, NPCs, economy, unlocks) and report skipped fields.
- Export raw originals and backups even when JSON parsing fails; include sanitized diagnostic manifest in ZIP.
- Android SAF/share-sheet export and SAF import. Reject zip-slip paths, oversized files, and unsupported formats; import only after preview and backup.

## Regression acceptance
1. v0.39.0 freshly saved career -> v0.40 load -> save -> restart -> load.
2. v0.39.1 career and backups -> same sequence.
3. Fixtures representing all available historical save schemas; log unsupported versions instead of destroying data.
4. Corrupted/truncated JSON: export still works, original unchanged.
5. Simulated interrupted save: previous valid backup remains recoverable.
6. On physical Samsung Android ARM64 device, save ZIP to Downloads and re-import via picker.
7. Four career slots and independent sandbox/free-mode slots.

## P1 — gameplay and UI
- Building-specific qualified personnel with actual throughput/capacity/quality effects.
- Two ski-rescue NPCs carry an unused stretcher outbound, transport patient inbound, treatment ~1–2 in-game hours.
- Single purchasable Portable Toilet, upgrades transform the same building; preserve legacy toilet saves.
- Radio: responsive layout, visible power switch, immediate station changes, synchronized playback offsets, no piercing FX.
- Menus: clear actions, readable stats, mobile touch and resolution scaling.
- Path/slope seams, snow-path contrast, NPC navigation, building-selection after construction.

## Visual themes
Theme selection must swap actual asset families, not just apply palette filters: terrain, trees, buildings, lifts, NPC silhouettes, UI, weather, animations. Targets: Alpine Realism, deliberately exaggerated Extreme Comic, Storybook, Monochrome Line Art, Geometric Low Poly. Preserve gameplay IDs and save compatibility across themes. Provide Android performance tiers.

## Release policy
Do not label any requirement complete until code changes, automated tests and device verification exist. No v0.40 APK publication until P0 gates pass.
