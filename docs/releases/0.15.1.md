# SkiZones 0.15.1 — Community & Feedback

## Community direkt im Spiel

- Im Hauptmenü führt der neue Eintrag **Community & Feedback** zu einem kompakten Dialog mit direkten Verweisen auf das SkiZones-Forum auf KoSchpendium (Discord), einen strukturierten GitHub-Bugreport, einen Feature-Vorschlag und den Community-Leitfaden.
- Externe Links werden nur auf ausdrücklichen Fingertipp oder Mausklick im vorhandenen Browser geöffnet. Das Spiel versendet von sich aus weder Spielstände noch Diagnose- oder Gerätedaten.
- Deutsche und englische Beschriftungen sowie ein Hinweis auf die Bedingungen der externen Plattformen sind enthalten.

## GitHub-Community und Dokumentation

- Die README verlinkt Discord, Bugreports, Feature-Ideen, offene Issues und Community-Regeln.
- Neue GitHub-Issue-Formulare erfassen bei Bugs Spielversion, Gerät, Bereich, Nachstellschritte, Ist- und Sollverhalten; Verbesserungsvorschläge erhalten eine eigene strukturierte Eingabe.
- Community-Leitfaden, Support-Informationen, Beitragsregeln und eine Vorlage für einen späteren GitHub-Discussions-Willkommensbeitrag wurden ergänzt.
- **Hinweis:** GitHub Discussions muss vom Repository-Administrator separat unter **Settings → Features → Discussions** aktiviert werden. Das bereits nutzbare Community-Forum befindet sich auf Discord unter https://discord.gg/AFXtwWvm.

## Android und Spielstände

**Android ARM64 Preview**, Android-Versionscode **20**. Version **0.15.1** ergänzt nur Community-Navigation, Übersetzungen und Dokumentation; Pisten-, Gäste-, Lift- und Spielstandlogik bleiben unverändert. Bestehende Spielstände behalten das bisherige Speicherformat. Die APK wird nach erfolgreicher Prüfung durch die GitHub-Actions-Pipeline veröffentlicht. Der Aufbau und die Installation sind in [ANDROID.md](../ANDROID.md) beschrieben.
