# SkiZones 0.27.1 — save re-entry hotfix

This is a focused save-access compatibility release based on v0.27.0. New 0.28/0.29 radio and hotel features remain in separate draft PRs until their checks pass.

- Discover older career/free-play saves and their backups even when an earlier migration marker is present.
- Re-run idempotent migration on startup without replacing any newer slot save or deleting original files.
- Offer valid legacy saves to the normal loading and recovery flow if a modern save is absent or damaged. Keep legacy mode isolated to the original free-play or first career slot.
- Let Continue and the career selector recognize verified historical saves; never start a new mountain over an existing unreadable modern save.
- Allow Android session restoration from a verified backup when the primary is unreadable; reject stale checkpoints when a newer valid primary exists.
- Add isolated regression tests for legacy fallback, slot isolation, migration-marker re-entry and intact legacy file hashes.
- Preserve the emergency mute of synthetic FX and the existing Alpine Radio library.

**Important:** Install this APK as an update, never by uninstalling the previous version or clearing app data. Android app-private saves are not backed up automatically. Do not describe actual device data as recovered until this APK has been tested against that save.
