# Willkommen bei SkiZones! ⛷️🏔️

Schön, dass du hier bist! SkiZones ist ein Android-Ski-Resort-Tycoon mit frei planbaren Pisten, Liften, lebendigen Gästen und Resortmanagement.

**Unser aktiver Community-Treffpunkt ist das SkiZones-Forum auf KoSchpendium (Discord): https://discord.gg/AFXtwWvm**

Hier in GitHub Discussions kannst du dich nach der Freischaltung der Funktion ebenfalls austauschen. Vorschläge für Forenkategorien:

- **Ankündigungen:** Neue Versionen, APKs und Changelogs.
- **Allgemeines Feedback:** Was macht Spaß, was sollte besser werden?
- **Ideen & Wünsche:** Neue Lifte, Pisten, Gebäude und Spielmechaniken.
- **Fragen & Hilfe:** Installation und Bedienung.
- **Resort-Galerie:** Zeig dein selbst gebautes Skigebiet.
- **Abstimmungen:** Welche Features soll SkiZones als Nächstes bekommen?

**Bug gefunden?** Bitte nutze das strukturierte [Fehlerformular](https://github.com/chekento/SkiZones/issues/new?template=bug_report.yml). **Konkrete Funktion gewünscht?** Nutze alternativ das [Ideenformular](https://github.com/chekento/SkiZones/issues/new?template=feature_request.yml).

Gehe respektvoll miteinander um, teile keine vertraulichen Daten und beachte die [Community-Regeln](COMMUNITY.md).

Viel Spaß beim Planen deiner Winterwelt! ❄️
